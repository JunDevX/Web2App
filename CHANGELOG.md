## Правила версионирования

Версии проекта следуют формату **MAJOR.MINOR.PATCH**:

- **MAJOR** - несовместимые изменения в API
- **MINOR** - новая функциональность (совместимая с предыдущей)
- **PATCH** - исправление ошибок

Примеры:
- `1.0.0` → `1.0.1` - исправление ошибки
- `1.0.0` → `1.1.0` - добавление новой функции
- `1.0.0` → `2.0.0` - кардинальные изменения
