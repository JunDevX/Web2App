# Руководство по контрибьютингу

Спасибо за интерес к Web2App! Мы приветствуем вклад от всех участников сообщества.

## Как внести свой вклад

### Сообщение об ошибках

Если вы нашли баг, пожалуйста откройте новый Issue с описанием:

1. **Название Issue** - кратко опишите проблему
2. **Версия** - укажите версию приложения и ОС
3. **Шаги для воспроизведения** - пошаговая инструкция
4. **Ожидаемое поведение** - что должно было произойти
5. **Фактическое поведение** - что произошло на самом деле
6. **Скриншоты** - если возможно, добавьте скриншоты

Пример:

```
Title: Ошибка при конвертации PNG с размером > 2000px

Version: 0.1.0, Windows 10

Steps to Reproduce:
1. Открыть Web2App
2. Загрузить PNG иконку размером 3000x3000px
3. Нажать "Создать"

Expected: Иконка успешно конвертируется
Actual: Появляется исключение OutOfMemoryException
```

### Предложение функций

Есть идея улучшения? Откройте Issue с префиксом **[FEATURE]**:

1. Опишите проблему, которую это решает
2. Предложите решение
3. Укажите альтернативные решения (если есть)
4. Дополнительный контекст

### Отправка Pull Request

1. **Fork** репозиторий
2. Создайте ветку для функции:
   ```bash
   git checkout -b feature/description-of-feature
   ```
3. Внесите изменения и добавьте тесты
4. Сделайте commit с понятным сообщением:
   ```bash
   git commit -m "feat: Add new feature description"
   ```
5. Push в вашу ветку:
   ```bash
   git push origin feature/description-of-feature
   ```
6. Откройте Pull Request с описанием изменений

## Рекомендации по разработке

### Стиль кода

Проект использует C# с Microsoft coding standards:

- **Классы и методы** - PascalCase
  ```csharp
  public class MainWindow
  {
      public void CreateApplication() { }
  }
  ```

- **Переменные и поля** - camelCase (приватные) или _camelCase (поля)
  ```csharp
  private string _selectedIconPath;
  private void ProcessInput(string userInput) { }
  ```

- **Константы** - UPPER_CASE
  ```csharp
  private const string CONFIG_FILE_NAME = "config.json";
  ```

- **Отступы** - 4 пробела
- **Скобки** - Allman style
  ```csharp
  if (condition)
  {
      DoSomething();
  }
  ```

### Комментарии

- Документируйте сложную логику
- Используйте XML comments для публичных членов:
  ```csharp
  /// <summary>
  /// Конвертирует PNG изображение в ICO формат.
  /// </summary>
  /// <param name="pngPath">Путь к PNG файлу</param>
  /// <param name="icoPath">Путь для сохранения ICO файла</param>
  private void ConvertPngToIco(string pngPath, string icoPath)
  {
  }
  ```

### Структура коммитов

Используйте понятные сообщения коммитов:

- `feat:` - новая функция
- `fix:` - исправление ошибки
- `docs:` - изменение документации
- `refactor:` - рефакторинг кода
- `test:` - добавление или изменение тестов
- `chore:` - обновление зависимостей, конфигурации

Примеры:
```bash
git commit -m "feat: Add support for custom window size"
git commit -m "fix: Handle empty URL validation"
git commit -m "docs: Update installation instructions"
git commit -m "refactor: Simplify icon conversion logic"
```

### Тестирование

Перед отправкой Pull Request:

1. Протестируйте локально:
   ```bash
   dotnet build
   dotnet run
   ```

2. Проверьте компилирование без ошибок
3. Убедитесь, что приложение запускается без исключений
4. Проверьте новую функцию в разных сценариях

### Требования к Pull Request

- Описание того, что вы делаете
- Ссылка на связанный Issue (если есть)
- Скриншоты для UI изменений
- Проверка, что код следует guidelines
- Все тесты должны проходить

## Процесс обзора

1. Минимум один maintainer проверит ваш PR
2. Могут быть запрошены изменения
3. После одобрения PR будет merged
4. Ваше имя добавится в CHANGELOG
