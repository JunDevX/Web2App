Установка

Как запустить готовую сборку

Три шага от архива с GitHub до рабочего приложения на рабочем столе.

Скачайте архив

Нажмите «Скачать Web2App-windows.zip» выше — файл всегда берётся из последнего релиза.

Распакуйте архив

Извлеките содержимое zip-файла в любую удобную папку на диске.

Запустите Web2AppLauncher.exe

Откройте распакованную папку и запустите Web2AppLauncher.exe — приложение готово к работе.

Скачивайте Web2App только с официального репозитория github.com/JunDevX/Web2App. Разработчик не распространяет программу через сторонние сайты.

Для разработчиков

Сборка из исходного кода

Хотите изменить проект под себя или собрать его вручную — вот команды для Visual Studio и .NET CLI.

# 1. Клонируйте репозиторий git clone https://github.com/JunDevX/Web2App.git cd Web2App # 2. Откройте проект в Visual Studio start Web2AppLauncher.sln # 3. Восстановите зависимости NuGet dotnet restore # 4. Соберите проект dotnet build # 5. Запустите приложение dotnet run

Системные требования

Что нужно перед установкой

Windows 7 или новее

Подходит для всех актуальных редакций Windows, 32- и 64-разрядных.

.NET 8.0 Runtime

Уже включён в архив готовой сборки — отдельно устанавливать не требуется.

Microsoft Edge WebView2

Обычно уже установлен в Windows 10/11; при необходимости система предложит установить его.

Свободное место на диске

Каждое созданное приложение хранит данные в собственной изолированной папке.
