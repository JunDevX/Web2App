О программе

Одна утилита, чтобы завернуть сайт в нативное окно

Web2App (W2A) — это утилита на C#, построенная на WPF и WebView2. Она берёт адрес сайта или веб-приложения и превращает его в отдельную программу для Windows: со своим значком, ярлыком на рабочем столе и собственной изолированной директорией.

Каждое созданное приложение работает независимо от остальных: у него свой User-Agent, своя конфигурация в формате JSON и своё окружение WebView2. Это удобно для веб-сервисов, панелей администрирования и любых сайтов, которыми хочется пользоваться как обычной программой.

Возможности

Что умеет Web2App

Полный набор инструментов, чтобы превратить веб-страницу в приложение и настроить его под себя.

Приложение из веб-адреса

Укажите URL — Web2App создаст под него отдельное настольное приложение на базе WebView2.

Свои иконки

Поддержка пользовательских иконок в форматах ICO и PNG для готового приложения.

Автоконвертация PNG → ICO

Загруженное изображение PNG автоматически преобразуется в формат ICO без сторонних программ.

Ярлык на рабочем столе

Готовое приложение сразу получает ярлык, чтобы запускать его как любую другую программу.

Свой User-Agent

Для каждого приложения можно задать собственный User-Agent — независимо от остальных.

Изолированная директория

Каждое приложение хранит данные и кэш WebView2 в собственной папке, не пересекаясь с другими.

Конфигурация в JSON

Все настройки приложения сохраняются в понятном JSON-файле — их легко посмотреть и перенести.

Как это работает

От ссылки до готового приложения — три шага

01

Укажите адрес сайта

Вставьте URL веб-страницы или веб-приложения, которое нужно превратить в программу.

02

Настройте иконку и параметры

Выберите иконку ICO или PNG, задайте User-Agent и другие параметры будущего приложения.

03

Получите готовое приложение

Web2App создаёт изолированную папку, ярлык на рабочем столе и запускает приложение через WebView2.

Требования

Что нужно для работы Web2App

Windows 7 или новее

Приложение работает на всех актуальных версиях Windows.

.NET 8.0

Среда выполнения .NET 8.0 для Windows — уже включена в сборку с готовым релизом.

Microsoft Edge WebView2

Рантайм WebView2 используется для отображения веб-страницы внутри приложения.

Интернет-соединение

Нужно для загрузки страниц, из которых собираются приложения.
