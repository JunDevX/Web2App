# README Translation Guide

## Мы нуждаемся в вашей помощи!

Если вы хотите помочь в переводе README.md на другие языки, мы будем очень благодарны!

## Как помочь?

### Способ 1: Создание Issue

1. Откройте новую Issue
2. Используйте название: `[TRANSLATION] Add README translation for {Language}`
3. В описании укажите:
   - Какой язык вы хотите перевести
   - Ссылку на оригинальный README.md
   - Примечания (если есть)

Пример:
```
Title: [TRANSLATION] Add README translation for French (Français)

Description:
Я хотел бы перевести README.md на французский язык.
Я готов к этому и смогу завершить перевод в течение недели.
```

### Способ 2: Pull Request (Рекомендуется)

1. Fork репозиторий
2. Создайте ветку:
   ```bash
   git checkout -b translation/add-{language}-readme
   ```
3. Переведите оригинальный README.md
4. Сохраните файл в папке `languages/`:
   ```
   languages/readme-{language_code}.md
   ```
5. Создайте Pull Request с описанием

### Правила для переводов

- Переводите весь контент README.md полностью
- Сохраняйте структуру и форматирование
- Используйте стандартные языковые коды (en, fr, de, es, ru, zh, ja и т.п.)
- Используйте понятный и профессиональный язык
- Проверьте орфографию и грамматику

### Примеры файлов

```
languages/
├── readme-en.md      # Английский
├── readme-fr.md      # Французский
├── readme-de.md      # Немецкий
├── readme-es.md      # Испанский
├── readme-ru.md      # Русский (текущий)
├── readme-zh.md      # Китайский
└── readme-ja.md      # Японский
```

# README Translation Guide

## We Need Your Help!

If you want to help translate the README.md into other languages, we would be very grateful!

## How to Help?

### Method 1: Create an Issue

1. Open a new Issue
2. Use the title: `[TRANSLATION] Add README translation for {Language}`
3. In the description, specify:
   - Which language you want to translate
   - Link to the original README.md
   - Any notes (if applicable)

Example:
```
Title: [TRANSLATION] Add README translation for Spanish (Español)

Description:
I would like to translate README.md into Spanish.
I am ready for this and will be able to complete the translation within a week.
```

### Method 2: Pull Request (Recommended)

1. Fork the repository
2. Create a branch:
   ```bash
   git checkout -b translation/add-{language}-readme
   ```
3. Translate the original README.md
4. Save the file in the `languages/` folder:
   ```
   languages/readme-{language_code}.md
   ```
5. Create a Pull Request with a description

### Translation Rules

- Translate the entire README.md content completely
- Preserve structure and formatting
- Use standard language codes (en, fr, de, es, ru, zh, ja, etc.)
- Use clear and professional language
- Check spelling and grammar

### File Examples

```
languages/
├── readme-en.md      # English
├── readme-fr.md      # French
├─�� readme-de.md      # German
├── readme-es.md      # Spanish
├── readme-ru.md      # Russian (current)
├── readme-zh.md      # Chinese
└── readme-ja.md      # Japanese
```

## Languages We Need

We would be especially grateful for translations into:

- French (Français) - `readme-fr.md`
- German (Deutsch) - `readme-de.md`
- Spanish (Español) - `readme-es.md`
- Chinese Simplified (简体中文) - `readme-zh.md`
- Japanese (日本語) - `readme-ja.md`
- Portuguese (Português) - `readme-pt.md`
- Italian (Italiano) - `readme-it.md`
- Korean (한국어) - `readme-ko.md`

But we will gratefully accept translations into any language!

## Review Process

1. You create an Issue or PR with your translation
2. Maintainer checks the quality of the translation
3. If edits are needed - you will be asked to make them
4. After approval, your translation is added to the project
5. Your name will appear in CONTRIBUTORS.md as a translator

## Recognition

All translators will be listed in the CONTRIBUTORS.md file with:
- Name
- GitHub profile
- Languages they translated

Thank you for helping popularize Web2App around the world!
